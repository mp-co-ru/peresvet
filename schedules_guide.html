Расписания

Расписание генерирует события по времени: раз в 15 минут, раз в час, раз в сутки. Само по себе оно ничего не делает — его выбирают инициатором вычислительного метода, и метод запускается при каждом срабатывании. Так считают сменные и суточные итоги, формируют отчёты, опрашивают внешние системы.

Настройка

  1. В конфигураторе в меню папки «Расписания» выберите Новое расписание.

  2. Задайте начало, конец и шаг. Шаг указывают в секундах, минутах, часах или днях.

  3. Нажмите Записать.

Если ничего не менять, расписание срабатывает раз в час, начиная с момента создания.

Поле

Смысл

Начало

Момент первого срабатывания. Следующие идут через каждый шаг от него: при начале в 08:00 и шаге 8 часов — в 08:00, 16:00, 00:00.

Конец

После этого момента расписание больше не срабатывает. Пусто — без конца.

Шаг

Промежуток между срабатываниями — целое число не меньше 1.

Выключенное расписание (снят признак «Активный») не срабатывает. Изменения настроек применяются сразу.

Запуск метода

  1. Откройте вычислительный метод (тип 0) у тега.

  2. На вкладке Инициаторы → Расписания выберите расписание.

  3. Запишите метод.

При каждом срабатывании платформа вызывает метод с моментом срабатывания: параметры «Данные тега(-ов)» читают значения на этот момент, и результат записывается в тег с этой же меткой времени. Подробно — в разделе Методы.

Одно расписание может запускать сколько угодно методов.

Через API расписания создают запросом POST /v1/schedules/, см. Расписания.
