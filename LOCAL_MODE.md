# Локальный режим установки

## Введение

Локальный режим предназначен для установки платформы в условиях ограниченного или отсутствующего доступа к интернету.

## Как работает локальный режим

При активации локального режима:
1. Все системные зависимости (libldap2-dev, libsasl2-dev, slapd, ldap-utils) устанавливаются на исходниках
2. Все Python-зависимости (из requirements.txt, fastmcp, aiohttp) устанавливаются на исходниках
3. Подготовленные зависимости включаются в дистрибутив
4. Docker-образы используют предустановленные зависимости вместо установки во время сборки

## Как использовать

### Шаг 1: Подготовка дистрибутива с локальным режимом

```bash
./packaging/build_dev_distribution.sh --local
```

Это создаст архив в `dist/peresvet-dev-<version>.tar.gz`, который содержит:
- Исходный код платформы
- Python wheels (как обычно)
- Подготовленные системные пакеты (`/apt-cache/`)
- Подготовленные Python-пакеты (`/python-site-packages/`)

### Шаг 2: Распаковка дистрибутива

Распакуйте архив на целевом сервере:

```bash
tar -xzf dist/peresvet-dev-<version>.tar.gz
cd peresvet-dev-<version>
```

### Шаг 3: Запуск

Запустите платформу с флагом `--local`:

```bash
./run_one_app.sh --local
```

Или установите переменную окружения в `.env`:

```bash
LOCAL_MODE=true
```

## Сборка Docker-образов в локальном режиме

Когда `LOCAL_MODE=true`, Docker-образы:

### one_app
- Используют предустановленные системные пакеты из `/preinstalled/apt-cache/`
- Используют предустановленные Python-пакеты из `/preinstalled/python-site-packages/`
- Устанавливают slapd только один раз на этапе подготовки

### mcp_peresvet
- Использует предустановленные Python-пакеты (fastmcp, aiohttp)

### grafana
- Использует предустановленные системные пакеты (если были установлены)

## Дополнительные скрипты

### Очистка подготовленных зависимостей

При необходимости очистите подготовленные зависимости:

```bash
./cleanup_local_dependencies.sh
```

## Примечания

- Локальный режим увеличивает размер дистрибутива (примерно на 200-500 МБ)
- Подготовленные зависимости зависят от версии Python и операционной системы
- При обновлении Python или системных библиотек может потребоваться повторная подготовка

## Устранение неполадок

### Ошибка: "failed to solve: failed to compute cache key: failed to calculate checksum of ref ...: "/preinstalled/apt-cache": not found"

Это нормально, если локальный режим не активирован или зависимости не были подготовлены. Docker просто игнорирует отсутствующие файлы.

### Ошибка: "No module named 'fastmcp'"

Убедитесь, что:
1. Локальный режим активирован (`LOCAL_MODE=true`)
2. Подготовленные Python-пакеты были успешно скопированы
3. В `python-site-packages/` есть модуль `fastmcp`

### Ошибка: "slapd not found"

Убедитесь, что:
1. Системные пакеты были успешно подготовлены
2. В `apt-cache/` есть пакет `slapd`
