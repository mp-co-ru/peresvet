Данные тегов

Значения тегов читаются запросом GET /v1/data/ и пишутся запросом POST /v1/data/. Каждое значение — точка [x, y, q]: метка времени, значение и код качества (Коды качества).

Чтение

GET /v1/data/

Параметр

Смысл

tagId

Тег или список тегов. Обязательный.

start, finish

Начало и конец периода: целое число микросекунд или строка ISO 8601. finish по умолчанию — текущий момент.

count

Сколько значений вернуть.

timeStep

Шаг между значениями в микросекундах.

maxCount

Наибольшее число значений в ответе (обычно ширина графика в пикселях).

actual

Только значения, реально записанные в хранилище, без вычисленных.

value

Отбор по значению.

format

Метки времени строками ISO 8601 в часовом поясе сервера.

operation, params

Операция и её параметры для интеграционного тега (Интеграционные хранилища).

Без start и count запрос возвращает текущее значение тега на момент finish. Как сочетаются ключи и что именно возвращается в каждом случае, подробно разобрано с примерами в разделе Исторические данные.

Ответ:

{
  "data": [
    {
      "tagId": "<id тега>",
      "data": [
        ["2026-11-17T19:10:00+03:00", 21.5, null],
        ["2026-11-17T19:11:00+03:00", 21.7, null]
      ]
    }
  ]
}

Выключенный тег и тег, которого нет, в ответ не попадают. Если тег не привязан ни к хранилищу, ни к методу чтения, ответ — 424.

Другие параметры адреса, не перечисленные в таблице, передаются методу чтения тега как часть запроса клиента (см. Методы).

Тег «Видеопоток» отвечает на этот запрос не точками, а видео или снимком, см. Видеопоток: API.

Запись

POST /v1/data/

{
  "data": [
    {
      "tagId": "<id тега>",
      "data": [
        ["2026-11-17T19:10:00+03:00", 21.5],
        [1794931860000000, 21.7, 0]
      ]
    },
    {
      "tagId": "<id другого тега>",
      "data": [["Насос включён"]]
    }
  ]
}

data — список тегов, у каждого свой список точек. Точку можно задать так:

Точка

Что записывается

[x, y, q]

Значение y с меткой x и кодом качества q.

[x, y]

Значение y с меткой x, качество нормальное (null).

[y]

Значение y с текущей меткой времени.

[]

null с текущей меткой времени.

Метка x — целое число микросекунд с 1970-01-01 UTC или строка ISO 8601. Строка без часового пояса считается временем UTC. Во второй точке примера 1794931860000000 — это 2026-11-17T16:11:00Z, то есть 19:11 по Москве.

Для интеграционного тега рядом с data можно передать operation (имя SET-операции) и params (её параметры), см. Интеграционные хранилища.

Ответ 200 — пустой объект. Для интеграционного тега ответ может содержать data с тем, что вернула операция.

Не каждая точка попадает в хранилище:

  • в выключенный тег ничего не пишется;

  • точка, отличающаяся от последней записанной меньше чем на значимое отклонение тега (prsMaxLineDev), отбрасывается;

  • точка с другим кодом качества записывается всегда;

  • повтор null с тем же качеством отбрасывается.

Подробно о значимом отклонении — в описании атрибутов тега (Теги).

Время в состояниях

GET /v1/datafunc/ принимает те же параметры, что и GET /v1/data/, и считает, сколько времени тег провёл в каждом своём значении за период. Удобно для тегов, в которых записан код состояния: «работа», «простой», «авария».

Без timeStep по каждому тегу приходит одна точка на момент finish. Её значение — объект «код состояния → длительность в микросекундах»:

{
  "data": [
    {
      "tagId": "<id тега>",
      "data": [
        ["2026-11-17T20:00:00+03:00", {"1": 3000000000, "2": 600000000}, null]
      ]
    }
  ]
}

С timeStep период делится на интервалы такой длины, и такой объект приходит для каждого интервала.
