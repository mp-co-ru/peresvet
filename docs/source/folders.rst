Папки
~~~~~

Пользовательская папка (класс ``prsFolder``) группирует узлы в дереве
и больше ни на что не влияет. Отдельного ресурса для папок в API нет:
папку создают тем же запросом, что и сущность ветки, в которой она лежит,
с полем ``"folder": true``. Без этого поля (по умолчанию оно ``false``)
запрос создаёт обычный узел.

Папка в корне ветки объектов, запрос ``POST /v1/objects/``:

.. code-block:: json

   {"folder": true, "attributes": {"cn": "Режимы работы"}}

Пустой ``parentId`` означает корень ветки, как при создании объекта или
тега. Чтобы положить папку внутрь объекта или другой папки, укажите
их идентификатор.

Папка для тегов внутри объекта, запрос ``POST /v1/tags/``:

.. code-block:: json

   {
     "folder": true,
     "parentId": "<id объекта или папки>",
     "attributes": {"cn": "Счётчики"}
   }

Какой запрос где создаёт папку:

.. list-table::
   :header-rows: 1

   * - Запрос
     - Где появляется папка
     - Что можно положить внутрь
   * - ``POST /v1/objects/``
     - ветка объектов
     - папки, объекты, теги
   * - ``POST /v1/tags/``
     - ветка тегов или объект
     - папки, теги
   * - ``POST /v1/connectors/``
     - ветка коннекторов
     - папки, коннекторы
   * - ``POST /v1/schedules/``
     - ветка расписаний
     - папки, расписания
   * - ``POST /v1/dataStorages/``
     - ветка хранилищ
     - папки, хранилища
   * - ``POST /v1/methods/``
     - каталог методов
     - папки, определения методов

Тревоги папок не имеют: запрос ``POST /v1/alerts/`` с ``"folder": true``
вернёт ``422``.

Правила:

* Имя ``system`` зарезервировано.
* У папки хранятся только ``cn``, ``description``, ``prsActive``
  и ``prsIndex``.
* Папки читают тем же ``GET`` сущности с фильтром ``objectClass=prsFolder``.
  Имя корня ветки (``objects``, ``tags``, ``connectors``, ``schedules``,
  ``dataStorages``, ``methods``) можно указать в ``base``.
* Узлы внутри папки не видны при ``scope=1`` от родителя папки, их
  возвращает ``scope=2``.
* Изменение и удаление — ``PUT`` и ``DELETE`` той же сущности
  с идентификатором папки. Удаление удаляет всё содержимое папки.
* Перенести папку в другую ветку или внутрь её самой нельзя.
* Права на папку — права сущности её ветки (``prsObject.create`` и т.д.),
  отдельных действий для папок нет.
