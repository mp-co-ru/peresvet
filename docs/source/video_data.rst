.. _video_data:

Работа с видеоданными
=====================

Платформа принимает видео с IP-камер по RTSP, хранит архив, показывает
живой поток, снимки и записи в конфигураторе и управляет поворотом камер.
Камера заводится в модели как коннектор, а смотрят её через тег типа
«Видеопоток».
