Компоненты системы
------------------

Платформа состоит из собственных сервисов и нескольких свободных
программных продуктов. При обычном запуске каждый компонент работает
в своём Docker-контейнере.

#. **Сервисы платформы.**
   Собственный код МПК-Пересвет. Его можно запустить одним приложением
   (контейнер ``one_app``, так работает стандартная поставка) или набором
   отдельных микросервисов на разных серверах.
#. **Сервисы видео.**
   Захват видео (``prs-video-capture``) держит соединение с камерами
   и пишет архив, отдача видео (``prs-video-delivery``) отвечает клиентам.
   См. :ref:`video_cameras`.
#. **OpenLDAP.**
   Хранит иерархию модели: объекты, теги, тревоги, методы, коннекторы,
   расписания, хранилища и связи между ними.
#. **RabbitMQ.**
   Брокер сообщений. Через него сервисы платформы общаются между собой,
   а коннекторы по протоколу MQTT передают данные в платформу.
#. **Redis.**
   Кэш сервисов: настройки тегов и хранилищ, подписки методов на события
   и т.п. Сервисам не нужно каждый раз читать их из LDAP.
#. **PostgreSQL.**
   Хранилище истории тегов и тревог по умолчанию. Историю можно хранить
   и в нескольких базах одновременно, в том числе разных типов.
#. **Grafana.**
   Веб-интерфейс. Главная панель — конфигуратор модели; там же строят
   экраны мониторинга.
#. **Nginx.**
   Единая точка входа: принимает HTTPS-запросы и распределяет их между
   компонентами платформы.
#. **MCP-серверы** (по желанию).
   Дают ИИ-агентам доступ к платформе и к Grafana, см. :ref:`mcp`.
