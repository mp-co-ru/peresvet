Описание

МПК-Пересвет — платформа для построения моделей технических объектов. Модель описывает, из чего состоит объект, какие у него параметры и как он себя ведёт. На её основе платформа собирает данные с оборудования, хранит историю, считает производные величины, следит за тревогами и запускает действия по событиям и расписанию.

Где применяется:

  1. Промышленная автоматизация: SCADA, диспетчеризация и мониторинг, MES.

  2. Умный дом и умное здание.

  3. Программно-аппаратные комплексы, в которых нужна своя модель объекта.

Из чего строится модель

Основа модели — иерархия. В ней лежат объекты (предприятие, цех, агрегат, датчик), у объектов — теги (температура, давление, ток), у тегов — тревоги и методы. Рядом с объектами в той же иерархии описана информационная система: коннекторы, которые приносят данные с оборудования, хранилища данных, где лежит история тегов, и расписания, которые запускают задачи по времени.

Поведение модели задают методы. Метод — программа, которую платформа вызывает, когда меняется тег или срабатывает расписание. Методы считают значения вычисляемых тегов, проверяют сложные условия тревог, отвечают на чтение и запись тегов, обращаются к внешним системам.

Термины подробно разобраны в разделе Терминология.

Как выглядит работа с платформой

  1. Платформу ставят на сервер с Docker одной командой (Установка и запуск).

  2. В браузере открывают Grafana. Главная панель Grafana — конфигуратор: в нём собирают иерархию объектов и тегов, настраивают коннекторы, хранилища, тревоги и методы.

  3. Коннекторы, установленные рядом с оборудованием, начинают присылать значения тегов (Коннекторы). Видеокамеры подключаются так же, коннектором (Подключение видеокамер).

  4. История тегов попадает в хранилище данных и читается запросом GET /v1/data/ (Исторические данные).

  5. Экраны мониторинга строятся в той же Grafana (Создание экранов в Grafana). Внешние системы работают с платформой через HTTP API.

Пошаговое построение модели с нуля разобрано в базовом курсе.

Редакции

Есть две редакции платформы: открытая и промышленная. Функции модели, сбора и хранения данных у них общие. Открытая редакция не проверяет права доступа: любой клиент, которому доступен адрес платформы, может выполнить любой запрос. Промышленная редакция подключает аутентификацию и авторизацию через точку расширения ядра, см. Точки расширения безопасности и Настройка безопасности промышленной редакции.
