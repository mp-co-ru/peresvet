Теги

Адрес — /v1/tags/. Запросы те же, что у всех узлов модели (Узлы модели: общие правила), включая копирование POST /v1/tags/copy.

Родитель тега — объект или пользовательская папка в ветке объектов или тегов. Без parentId тег создаётся в корне ветки «Теги».

Атрибуты тега

Кроме общих атрибутов (Узлы модели: общие правила), у тега есть такие:

Атрибут

Смысл

По умолчанию

prsValueTypeCode

Тип значений: 0 — целое, 1 — вещественное, 2 — строка, 4 — JSON, 5 — интеграционный (Интеграционные хранилища), 6 — видеопоток (Подключение видеокамер).

1

prsMaxLineDev

Значимое отклонение. Для чисел: новое значение, отличающееся от последнего записанного меньше чем на эту величину, не записывается. Для строк и JSON: любое ненулевое значение отсекает повтор того же значения. 0 — записывать всё. Значение с другим кодом качества записывается всегда.

0

prsStep

Шаговый тег: между двумя записанными значениями значение не интерполируется, а остаётся прежним до следующей точки. См. Правила работы с данными.

false

prsUpdate

true — новое значение с той же меткой времени заменяет старое. false — на одну метку времени хранится несколько значений.

true

prsMeasureUnits

Единицы измерения, например °C.

—

Атрибуты prsArchive, prsCompress и prsDefaultValue API принимает и хранит, но платформа их сейчас не использует.

Пример — вещественный тег «Температура» в объекте:

POST /v1/tags/

{
  "parentId": "<id объекта>",
  "attributes": {
    "cn": "Температура",
    "prsValueTypeCode": 1,
    "prsMeasureUnits": "°C",
    "prsMaxLineDev": 0.1
  }
}

Источник и хранилище

Сам по себе тег данных не получает и не хранит. Его связывают:

  • с хранилищем — полем linkedTags запроса к хранилищу (Хранилища данных);

  • с коннектором — полем linkedTags запроса к коннектору (Коннекторы);

  • с методами — дочерними узлами методов (Методы).

Запрос POST /v1/tags/ к хранилищу тег не привязывает. Флажок «Привязка к хранилищу по умолчанию» в конфигураторе делает это отдельным запросом после создания тега.

Значения тега читаются и пишутся запросами /v1/data/, см. Данные тегов.
