# Черновик страницы МПК-Пересвет

Локальный макет новой страницы платформы. Существующую
[ioterra.ru/mpc-peresvet](http://ioterra.ru/mpc-peresvet) не заменяет.

Открыть: `website/mpc-peresvet/index.html`

Палитра взята с логотипа Пересвета: оранжевый `#fb6b3b` и тёмно-коричневый `#4c2c2c`. Не палитра IoTerra OEE.

Ориентир по структуре — тот же, что у макета IoTerra OEE:
[10 критериев продающего сайта](https://vc.ru/marketing/1061988-chek-list-10-kriteriev-prodayushego-saita-v-2024).

## Чем эта страница отличается от текущей на сайте

Текущая карточка говорит про импортозамещение и «информационно-аналитическое обеспечение».
Макет говорит про **что можно собрать**: диспетчеризация/SCADA, MES, умный дом,
отраслевые приложения, карты и видео в Grafana.

Карты и видео в базовом дистрибутиве Пересвета ещё не оформлены отдельным модулем.
На странице это не прячется и не продаётся как «уже в коробке»: Grafana это умеет,
подключение — на внедрении, без смены платформы.

## Что учтено

1. Навигация с любой точки: шапка, подвал, телефон, мобильное меню.
2. Первый экран — оффер и CTA «демо / позвонить», не перечень микросервисов.
3. Макеты экранов — CSS, без стоковых фото и без чужих дашбордов.
4. CTA каждые 2–3 блока, плюс нижняя панель на телефоне.
5. Доказательства без выдуманных отзывов: сущности платформы, IoTerra OEE как живой пример, открытый код.
6. Заголовки про задачу: модель объекта, сбор → обработка → действие → экран.
7. Связь: форма, телефон [+7 499 393-00-40](tel:+74993930040), [info@ioterra.ru](mailto:info@ioterra.ru).
8. Короткая форма: имя и телефон.
9. Одно мягкое окно «показать контур» — раз за сессию.
10. Мобильная вёрстка и крупные кнопки.

## Как перенести в Tilda

1. Отдельная страница-черновик, не вместо текущей.
2. Загрузить `logo.svg` (эмблема Пересвета). Макеты экранов либо оставить HTML/Zero-блоками, либо заменить снимками стенда.
3. Форму заменить формой Tilda с согласием на обработку данных.
4. Попап в Tilda — блок Catch / Zero, не чаще одного раза за визит.
5. Блоки «Карты» и «Видео» при переносе не усиливать до «входит в поставку», пока нет готовых шаблонов.
