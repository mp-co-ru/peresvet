Платформа-конструктор

МПК-Пересвет: приложения автоматизации для разных объектов

На платформе собирают информационные системы вокруг модели технического объекта: иерархия, параметры, события и действия. Один и тот же каркас служит диспетчеризации, производственному контуру, умному зданию и программно-аппаратному комплексу.

Что это

Модель объекта, а не плоский список метрик

Платформа стоит над хранилищем истории. У объекта есть параметры, по событиям запускаются методы, а через коннекторы данные не только читаются с поля, но и записываются обратно. Задача — автоматизация технического объекта, а не только сбор чисел.

Модель Иерархия объектов. У каждого свой набор тегов: температура, расход, состояние, расчёт.
Поле Коннекторы забирают значения и записывают команды во внешние источники.
Событие Изменение тега, тревога или расписание запускают метод и внешний процесс.
Какие приложения собирают

Одна платформа под разные объекты

Область применения — промышленная автоматизация, умный дом и здание, программно-аппаратные комплексы. Прикладную систему собирают на модели объекта, а не начинают инфраструктуру заново.

01

Диспетчеризация и мониторинг

SCADA-контур и диспетчерская: текущие значения, тревоги, экраны и запись команд в поле.

02

MES и производственные контуры

На платформе уже работает ИоТерра OEE: линия, смены, простои и план-факт.

03

Умный дом и здание

Комнаты, климат, протечки и сценарии: событие запускает метод, расписание держит режим.

04

Программно-аппаратные комплексы

Платформа как основа комплекса: модель, история, доступ и экраны вокруг конкретного объекта.

Из чего собирается система

Семь сущностей модели

01

Объект

Узел иерархии: предприятие, цех, агрегат, комната. У объекта свои параметры.

02

Тег

Параметр объекта. Значение приходит с поля или считается по другим тегам.

03

Тревога

Условие на теге. Срабатывание — отдельное событие, к нему можно привязать метод.

04

Метод

Действие на изменение тега, тревогу или расписание, в том числе внешний процесс.

05

Коннектор

Связь с полем: чтение значений и запись во внешние источники.

06

Хранилище

История значений. В открытой поставке по умолчанию используется PostgreSQL.

07

Расписание

Запуск по времени: отчёт, смена режима, периодический метод.

Как запускают

Архив релиза и Docker Compose

Открытая редакция публикуется в GitHub Release под лицензией Apache 2.0. Промышленная редакция поставляется отдельно. Для запуска нужен Docker Compose.

Релизы Установка
  1. Взять продуктовый архив Файл peresvet-product из релизов репозитория.
  2. Подготовить Docker Compose Платформа поднимается контейнерами. Состав и параметры описаны в документации по установке.
  3. Запустить run_one_app.sh Скрипт в корне поставки стартует платформу. Рядом лежит .env с параметрами по умолчанию.
  4. Собрать модель Дальше — объекты, теги, коннекторы и экраны Grafana под конкретную задачу.
